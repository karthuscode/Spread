# V2 Production Roadmap

## Production Goal

V2 begins only after the V1 playable graphical prototype exists and satisfies the V1 completion definition.

V2 is the polish phase. It builds presentation quality on top of the complete, integrated V1 experience without redefining the prototype milestone or using polish work to conceal incomplete core production.

## V2 Scope

V2 includes:

- character animations;
- idle loops;
- win animations;
- particles;
- screen effects;
- audio;
- UI polish;
- presentation improvements; and
- transition effects.

## Production Priorities

### Character Motion

Create character animations that preserve symbol readability, established silhouettes, and the shared Visual DNA. Idle loops should give the reels life without distracting from play. Win animations should make winning symbols feel responsive and rewarding.

### Effects

Add particles and screen effects where they clarify or reinforce spins, infection events, wins, and other important state changes. Effects should support readability rather than cover symbols, paylines, or results.

### Audio

Develop audio feedback for player input, reel activity, infection, wins, and presentation beats. Audio should strengthen timing and identity while remaining synchronized with the graphical experience.

### Interface and Presentation

Polish the UI hierarchy, spacing, materials, feedback states, and overall cohesion. Improve the presentation of the complete play loop and add transition effects between meaningful states.

## V2 Production Checklist

- [ ] Character animations
- [ ] Idle loops
- [ ] Win animations
- [ ] Particles
- [ ] Screen effects
- [ ] Audio
- [ ] UI polish
- [ ] Presentation improvements
- [ ] Transition effects

## V2 Entry Condition

V2 production may begin when V1 is officially complete: the full static symbol set and basic UI are integrated into a playable graphical build, the infection mechanic and paylines function, wins calculate correctly, and win highlighting clearly communicates results.

Any unresolved work required to meet that condition remains V1 work rather than V2 polish.
